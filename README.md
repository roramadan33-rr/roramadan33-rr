## 🚀 Featured Project

### [NetWatch: Enterprise Network Monitoring & Security System](https://github.com/roramadan33-rr/NetWatch-Network-Monitoring)
*Graduation Project*

A secure enterprise network with a real-time monitoring dashboard.

- Centralized identity with **Active Directory** (OUs, Groups, GPOs) and **FortiGate** least-privilege policies
- High-availability design: **VLANs, inter-VLAN routing, HSRP, RSTP, EtherChannel**
- **Python** backend + HTML/CSS/JS dashboard for device health, AD events, fault detection and network performance
- Validated with failover testing, routing verification, and security policy audits
